# Somankidy — Design system

Style C « Vert africain et beige » : naturel, chaleureux, institutionnel.

## Couleurs
- `--vert` #1E4D2B (identité, sidebar, boutons primaires)
- `--vert-2` #2F6B3F (hover, graphiques)
- `--or` #C9962B (accents, chiffres clés, numéros de plaques)
- `--terre` #B4552D (alertes douces, catégorie secondaire)
- `--beige` #F4ECDD (fond de l'app)
- `--sable` #E9DCC4 (bordures, séparateurs)
- `--blanc` #FFFDF8 (zones de travail / cartes)
- `--encre` #1C2118 (texte)

## Typographie
- Titres : Fraunces (serif, 600–700) — caractère institutionnel et chaleureux
- Texte / UI : Outfit (400–600)
- Chiffres : Outfit tabular-nums

## Motifs
- Bandes géométriques inspirées du bogolan (losanges, chevrons) en SVG, opacité 6–12 %, dans la sidebar et l'en-tête du tableau de bord.

## Layout
- Menu latéral gauche 272px (vert), repliable en tiroir < 1024px.
- Barre supérieure : recherche, bouton langue FR / SON, date.
- Contenu : max 1400px, padding 24–32px.
- Cartes : fond blanc cassé, bordure sable 1px, rayon 14px, pas d'ombre lourde.

## Composants
- Tableaux : en-tête beige, lignes séparées, actions à droite, recherche + filtres au-dessus.
- Plaques : fond vert, liseré or, numéro géant, nom de rue, QR code optionnel.
- Formulaires : modale latérale (drawer droit).

## Motion
- Apparition échelonnée des cartes au chargement de page (motion).
